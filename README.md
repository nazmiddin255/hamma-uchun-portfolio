# Hamma uchun portfolio (shablon)

![AI yordamida yaratilgan](https://img.shields.io/badge/AI%20yordamida-yaratilgan-3b82f6)

Oddiy, yengil, bitta sahifali portfolio sayt shabloni. Ko'k rang, tungi/kunduzgi rejim, UZ | EN tili.

**AI yordamida yaratilgan:** shablon AI yordamida yozilgan, lekin muallif kodni o'zi o'qib, sinab chiqqan va nima qilishini tushunadi.

## Qanday ishlatiladi (3 qadam)

1. Tepadagi yashil **Use this template** tugmasini bosing va o'z GitHub hisobingizda yangi repo yarating (nomi `portfolio` bo'lsin).
2. `malumot.js` faylini oching va ismingiz, kasbingiz, ko'nikmalaringiz, loyihalaringizni yozing. Rasmingizni `rasm.jpg`, rezyumeni `rezyume.pdf` nomi bilan repoga yuklang. Rasm kichik o'lchamda (taxminan 400x400) bo'lsin.
3. Repo **Settings → Pages** bo'limida "Deploy from a branch" → `main` → `/ (root)` ni tanlang. Bir necha daqiqadan keyin sayt `sizning-nom.github.io/portfolio` manzilida ochiladi.

## Fayllar

- `index.html`: sayt (tegish shart emas)
- `malumot.js`: **faqat shu faylni tahrirlaysiz**
- `README.md`: shu yo'riqnoma

Public repodagi hamma narsani boshqalar ko'ra va yuklab ola oladi. Pasport, telefon raqami kabi shaxsiy ma'lumotlarni sayt yoki repoga qo'ymang.
